# X2 起身动作重定向：问题诊断、处理与 GMR/UMR 实践对比

日期：2026-10-25。范围：本项目使用的 AMASS/CMU → SMPL-X → X2 起身参考生成流程。

## 1. 可用于汇报的核心结论

本阶段的目标是将人体起身动作转化为适配 X2 的运动学参考。我们先基于 GMR 建立了显式骨架映射和约束求解流程，后采用 UMR 的表面对应方法扩展动作库。实际难点集中于人体与机器人的形态及关节范围差异、接触点定义、时序连续性以及碰撞约束在滤波和重采样后的保持。

在本批片段中，UMR 输出获得了较好的主观自然度评价，适合继续扩展候选库；但它的原始输出同样存在穿地和自碰撞，最终候选依赖额外的平滑几何修正。GMR 的优势是任务结构清楚、便于定位和调整具体身体部位，但人工标定和任务权重之间存在明显耦合。上述属于项目实践结论，尚不是统一基准下的算法性能排名。

## 2. 问题如何表现、如何表述

| 问题 | 本项目中观察到的表现 | 汇报中建议使用的术语或句子 |
|---|---|---|
| 姿态伪影 | 手掌持续翘起、肩部突然扭转、倒地阶段腿部姿态异常 | “出现非自然关节姿态及局部补偿性运动，人体姿态未能直接映射为形态适配的机器人姿态。” |
| 时序伪影 | 侧躺阶段抽动、首帧附近颤抖、支撑切换时关节突变 | “逐帧姿态可求解，但缺乏足够时序一致性，表现为关节速度或加速度的局部尖峰。” |
| 地面穿透 | 手、脚等碰撞几何进入地面；单看腕关节原点可能看不出来 | “最小碰撞几何高度小于地面高度，存在几何非穿透约束违反。” |
| 自碰撞 | 手腕卡在腿部、肩部与大腿/膝部重叠 | “非相邻且未被合法过滤的刚体碰撞几何出现交叠。” |
| 动作目标不可达 | 腰俯仰长期贴近限位；强行跟随躯干会将误差转移到腕部或骨盆 | “部分人体目标与机器人运动学可达域及关节范围不兼容，形成目标跟踪与约束满足之间的冲突。” |
| 接触失真 | 腕点近地但掌面没有贴地，或看似支撑却未验证承重 | “接触候选的几何位置和朝向与实际支撑面不一致；几何接触不等于动力学有效支撑。” |
| 处理链引入伪影 | 平滑后重新穿透、30 Hz 通过但 50 Hz 插值后出现重叠 | “中间处理不保持原几何可行域，需要在最终输出采样率上重新验证。” |
| 末姿态任务不匹配 | 参考结束于半蹲，而成功条件要求站直 | “参考动作终态与下游任务目标不一致；这不是仅靠重定向误差指标就能判断的问题。” |

“伪影”是输出中的不自然现象，不是一种单独算法错误。抖动、错误关节分支、接触滑移等可以作为不同子类描述。

## 3. 实际诊断与修正路径

### 3.1 形态差异与目标可达性

人体和 X2 不仅总身高不同，躯干高度、肩宽、上臂和前臂比例也不同。单一全局缩放无法保证手部支撑和手腿间距同时合理。

GMR 流程中采用独立 T-pose 标定及分段位置映射：躯干高度比例约 0.820、肩宽约 0.943，上臂约 0.97–0.99，前臂到机器人腕端约 0.83–0.85。这里的机器人腕端不是人体解剖腕点，必须考虑局部任务帧偏移及方向差异。

此外，人体目标要求的骨盆—躯干相对俯仰约为 3–61°，其中约 69% 的目标帧超出当前 X2 腰 pitch 约 ±18° 的直接对应范围。这证明的是“该目标链的直接匹配存在冲突”，不是证明 X2 无法通过其他姿态完成起身。

处理方法是调整分段目标和任务优先级，在机械限位不变的前提下允许一定跟踪误差，而不是放宽真实关节范围强行匹配。

### 3.2 任务权重耦合和误差转移

降低骨盆 pitch 跟踪权重、提高躯干 pitch 权重后，GMR 的躯干平均方向误差由 21.61° 降至 9.64°；但骨盆方向误差从 0.92° 增至 13.56°，右腕 pitch 接近限位的帧数比例从 60.1% 增至 79.8%。

因此，“某个任务误差下降”不能直接等同于“整段动作质量提高”。需要同时观察姿态自然度、限位占比、碰撞间距、接触状态和连续性。

### 3.3 抖动、抽动与支撑切换

关节多解性、约束激活变化和互相冲突的软任务都可能造成局部突变；不能仅凭回放就将某一次抽动断定为唯一原因。

GMR 中加入以前一实际输出帧为目标的姿态正则，作用于腰、肩、肘和腕；首帧先进行重复求解。对于手部支撑阶段，采用更缓的任务进入/退出，并移除过强的固定腕肘目标，避免将补偿推向肩部。

在 140_01 的 3.3–4.1 秒窗口，右腕位置差分峰值加速度从 35.75 降至 13.78 m/s²，而右腕目标平均位置误差仅由 5.98 增至 6.04 cm。该指标说明局部连续性改善，不是接触力或动力学测量。

UMR 的现用流程保留 LQR 时序滤波，并额外加入根旋转增量预测软代价。原有滤波主要处理标量关节和根平移，不能据此认为根旋转也被同样平滑。预测旋转使用旋转群上的相对旋转，而非直接滤波四元数各分量。

### 3.4 地面穿透与自碰撞

首先检查碰撞几何，而非只检查可视网格、手腕原点或足踝原点。UMR 地面约束需要生成的求解模型中确实存在地面碰撞几何。

启用一次线性化约束并不保证最终输出完全无穿透；IK 后的 LQR、参考限速及重采样均可能改变几何关系。我们在最终轨迹上增加了带时间正则的约束修正：尽量保持原姿态，同时满足地面余量、适用自碰撞约束和硬限位，并惩罚修正量的帧间变化。

现用修正保持根旋转不变，允许小幅关节和根平移修正。没有把每帧统一抬高当作最终方案，也没有简单关闭自碰撞或过滤手腿相交来隐藏问题。

装配结构允许合法接触或相切，不应要求所有几何之间都有相同正间隙。检查和求解排除了同一刚体、直接相邻刚体和实际已配置的装配过滤对。特定容易在插值时重新碰撞的手膝对额外保留 1 mm 间隙。

### 3.5 手部支撑几何

人体手部、机器人腕关节及掌面不是同一参考点。只匹配腕点可能得到手掌翘起或掌面朝向不适合支撑的结果。

我们显式检查掌面候选位置和法向，区分手接近地面的候选时段，逐阶段引入几何支撑任务。左手支撑实验中去除了过强的固定中位姿态要求，延长支撑任务过渡，增加近限位缓冲和参考速度限制。

这些处理改善了几何姿态和过渡，不代表已经验证了掌部法向力、摩擦、质心支撑或实际负载能力。

修正版在原输出帧率上的全片段检查未检出超过 0.1 mm 阈值的适用自碰撞。最终 50 Hz 输出又独立复查：140_08 曾因插值重新出现约 0.44 mm 的手膝交叠，通过额外间隙修正后生成 v2；其他最终版本也按最终采样率验收。

最终候选完成了 MuJoCo 与 Isaac 的关节名称映射、根坐标系和 80 维 AMP 特征一致性检查。新增 139_16/17/18 与 140_09 全片段最大刚体位置误差约 0.063 mm。该数字表示跨模拟器 FK 一致性，不是对人体动作的重定向误差，也不是物理跟踪误差。

## 5. GMR 与 UMR：本项目实践对比

| 维度 | 本项目的 GMR 流程 | 本项目的 UMR 流程 |
|---|---|---|
| 对应方式 | 显式人体—机器人任务帧映射，配合位置/方向偏移和两阶段 IK | 学习规范姿态下的有序表面对应，进行对应点引导的约束重定向 |
| 适配重点 | 任务帧、分段比例、方向偏移、权重、手脚接触阶段 | 规范姿态、人体体型模板、表面对应质量及后续约束 |
| 可解释性 | 哪个任务导致误差比较容易定位，但多个任务间有耦合 | 能利用更丰富的表面形态信息；对应点质量的解释和诊断更复杂 |
| 我们观察到的效果 | 可建立俯卧基线；腕肩伪影、局部抖动和支撑姿态经历了较多逐项调整 | 本批动作主观自然度较好，较方便继续扩展多片段；仍存在厘米级几何穿透 |
| 时序处理 | 上一实际输出帧姿态正则、阶段过渡、参考速度限制等 | LQR、根旋转预测正则及带时间正则的几何修正 |
| 新体型准备 | 显式缩放和标定需要重新核对 | 本次为 CMU139、77 分别训练对应点；140 组复用同体型对应点 |
| 碰撞问题 | 地面和所选自碰撞约束仍需独立验证；部分修改将误差转移到其他部位 | 初始输出不自动无碰撞；平滑和重采样后仍需复查与修正 |
| 本阶段用途 | 作为显式映射与可解释诊断基线 | 作为当前扩展 X2 起身参考库的主要候选生成流程 |

两条流程都经过了项目定制，使用了不同的附加修正和参数。尚未进行同一片段集合、同一机器人模型、同一碰撞定义、同一误差指标及同一后处理预算下的统一消融。因此不宜写成“UMR 的准确率、效率或泛化能力全面优于 GMR”。目前也没有可支持运行速度对比的统一计时结果。

## 6. 实现和仿真问题应单独报告

- 早期 JSON 继承丢失默认配置、错误地复用体型模板、缺少地面碰撞几何：属于集成/配置问题，不能归因于算法固有缺陷。
- 姓名映射、四元数顺序和根速度参考点错误：属于数据接口问题，需靠跨模拟器一致性验证排查。
- Isaac 中的异常飞起、求解器选择、装配过滤和净接触力混入自碰撞：属于物理模型或仿真信号问题，不能直接作为 GMR/UMR 重定向优劣证据。
- 参考停在半蹲而任务要求稳定站立：应另行设计终态和站立策略，不能把人工延伸的末段当作原始人体动作的真实重建。

## 7. 汇报页组织建议

1. 问题页：放典型手掌翘起、手腿相交、肩腿相交和局部抽动截图；每张标明片段、时间和问题术语。
2. 处理页：用“分段标定 → 时序正则 → 几何约束修正 → 最终采样率复查”概括处理链。
3. 结果页：使用上面的 GMR 内部消融表和 UMR 修正表，明确它们不是跨方法统一性能比较。
4. 对比与下一步：说明本阶段采用 UMR 扩展参考库、保留 GMR 为基线；后续由 AMP/强化学习验证动力学跟踪、支撑和起身成功率。
