# UMR 局部修复 v5：139_17 撑手、140_02 髋腿衔接

对象始终为 prone_getup 清单第 3 条 UMR 139_17、第 4 条 UMR 140_02。结果另存 data/motions/umr_local_v5/，未替换原始参考、v4 或训练清单。

## 第 3 条：约 1 秒撑手抖动

从 v4 出发，在 0.35～1.90 s 对双臂关节做局部修正，0.30 s 平滑进入/退出，0.65～1.60 s 稳定两手世界位姿。不是只滤腕关节；保留根姿态与腿部，利用肩、肘、腕配合消除父链带来的手部运动。最大关节修正约 0.0341 rad（1.95°）。0.35～1.90 s 之外的关节位置逐元素保持不变。

| 右 | 0.00638 / 0.0000034 | 0.04479 / 0.000013 |

## 第 4 条：5.34 秒附近髋腿衔接

对 4.65～6.05 s 骨盆旋转在 SO(3) 切空间做局部平滑（sigma=0.16 s，边界渐变），最大根旋转改变约 9.56°。随后在原支撑时序下重做双脚锁定 IK，加入膝部伸直回避与局部髋腿/根位置二阶正则，避免锁脚时近伸直膝盖附近的快速再弯曲。膝部约束渐进达到 0.30 rad，不是逐帧事后截断。

## 验证与限制

两条导出候选经独立全帧原生几何审计：无超过 0.1 mm 容差的穿地或合法碰撞对穿插，硬限位通过。Isaac CPU 全片段回放的刚体位置、方向映射通过；最大位置误差约 0.063 mm。既有 AMP 身体解析速度与有限差分参考速度差异仍在，amp_consistency_passed 仍为 false，不把该项说成已通过。

只做了运动学、几何与时序修正，未验证动力学支撑、接触反力或力矩可行性。手部固定和支撑时刻是修复假设，需人工查看是否保留了所需动作风格。
