# UMR 联合时序修复 v7

针对 v6 的反馈：139_17 手腕端点平滑后，逐帧 IK 把高频补偿转移到了肩肘；140_02 多次局部滤波没有统一约束骨盆和世界躯干运动，存在较差的衔接。

## 第 3 条 UMR 139_17

从 v5 而非 v6 出发，重新优化 2.20～4.90 s 双臂 14 个关节。整条轨迹联合求解：关节二阶/三阶时序正则、肩肘腕整体关节参考、平滑的世界手腕与肘部位姿软目标，以及原生几何非穿透与硬限位。手腕目标不再强行逐帧精确跟踪，因此不会为极低的端点误差牺牲整条手臂平滑性。

3～4 s 左肘世界角加速度峰值约 159.4→12.6 rad/s²，右肘约 53.5→11.4；左肩滚转关节角加速度约 113.7→2.35，左腕滚转约 165.3→0.77。左右手腕刚体世界角加速度峰值约 11.6/10.3，略高于 v6 约 5 的端点指标，但明显低于原始抖动，且整条链同时改善。最大单关节位置修正约 0.163 rad。前面 1 秒的 v5 修复与后段脚部锁定保留，根位姿全段未改，区间外关节位置保持不变。

## 第 4 条 UMR 140_02

从 v4 重新构建 4.40～7.80 s 连续躯干轨迹，sigma=0.22 s 平滑骨盆旋转与世界躯干方向，联合优化腰部时序，最后重解腿部接地约束。复用 v5 的支撑脚锚点，膝部下限渐进达到 0.30 rad。不是在 v6 上继续叠加局部补丁。

5.0～6.8 s 躯干世界角加速度峰值约 54.9→2.29 rad/s²；该较宽区间覆盖了 v6 在约 5.2 s 留下的尖峰。完全支撑后足底净空约 2 mm，最大水平速度 <0.00004 m/s。

保留原参考末段的二次前倾；它不是本次平滑能自动决定删除的内容。原参考骨盆倾角存在约 25°→55° 的变化，若目标改为站起后持续直立，需要另做姿态目标版本。

## 检查与使用

两条候选独立原生几何审计、关节硬限位、Isaac CPU 完整回放的位置和方向映射通过，最大刚体位置差约 0.063 mm。既有 AMP 身体解析速度与参考有限差分速度误差仍在，amp_consistency_passed=false，不把它宣称为通过。未做动力学支撑或执行器验证。

原始 UMR、旧候选和训练清单未修改。最终候选位于 data/motions/umr_temporal_v7/；工具为 scripts/repair/repair_x2_reference_temporal.py。演示用 scripts/replay/replay_x2_reference.py --motion <对应NPZ> --viz kit --loop --slowdown 2。
