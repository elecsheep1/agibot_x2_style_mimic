# X2 近邻碰撞审计（2026-11-08）

只读检查，未修改资产、过滤规则、奖励或训练设置。当前训练使用 x2_ultra.usda，开启自碰撞。

## 覆盖范围

读取实际 USD 的 32 个刚体、30 个启用的凸包碰撞网格及已有过滤关系。使用实际网格点构建凸包，以本地 X2 关节树做离线距离查询。零姿态根相对刚体位置与 USD 的最大误差小于 0.1 mm；旋转矩阵元素误差约 0.00016。底座在 XML 原名 pelvis，审计显式映射为 base_link。

检查具有碰撞几何的树距离 1～3 的 82 对：直接相邻 28 对、两级 27 对、三级 27 对。没有碰撞网格的刚体不进入形状对。扫描 1476 个姿态，包括零姿态、31 关节各 13 个角度、500 个全限位随机组合、两个失败回合抽样、髋 roll 细扫描，以及八条参考动作每 10 帧抽样。

独立 GPU PhysX 64 环境悬空探针完成 404 个零姿态/单关节扫描状态，各状态只推进一个物理子步，检测初始几何响应；不运行训练。极限姿态力值不能作为正常运行或稳态力值。

## 新发现的装配干涉候选

| 接触对 | 触发姿态 | 离线最深穿入 | GPU 单子步接触峰值 |
|---|---|---:|---:|
| base_link / left_hip_roll_link | left_hip_roll=-0.235 rad，其他关节零 | 10.86 mm | 19504 N |
| base_link / right_hip_roll_link | right_hip_roll=+0.235 rad，其他关节零 | 10.85 mm | 15124 N |

零关节姿态两对间隙均约 2.65 mm。细扫描显示左 roll 从 -0.05 rad、右 roll 从 +0.05 rad 附近开始发生几何重叠（扫描步长 0.005 rad；不是精确接触阈值，也未包含 PhysX 接触偏置）。这发生在合法单关节内收范围内，不需要远端肢体绕到躯干才会触发，且左右对称。结合既有训练记录中相同配对的短时高力峰值，应优先作为近邻装配碰撞问题处理。

八条参考动作的抽样姿态中，未发现未过滤两级/三级近邻凸包穿入；策略仍可探索到该髋内收区域。其余未过滤两级/三级近邻未检出超过 1 mm 穿入，GPU 单关节扫描也没有检出其他近邻接触对超过 1 N。

## 不应作为装配过滤的接触

GPU 极限单关节扫描还检出了腿/肩、腿/手臂等远端接触，属于肢体可达空间相撞；极限角度不能作为合理姿态的证明，不建议排除。失败回合 603 的右踝/左膝、1348 的左膝/左肩同样应保留检测。

## 处理建议与限制

优先只针对 base / 左右 hip_roll 两对：检查厂家几何和实机内收空间；若确认是装配凸包重叠，在物理层增加这两个精确配对过滤，与 G1 示例的处理一致。单纯奖励豁免只会去掉处罚，不会去掉物理挤压力。不要屏蔽全部两级近邻。

离线 MuJoCo 凸包算法和 PhysX cooking/contact offset 有差异；随机/有限采样不能证明连续关节空间不存在其他问题。已完成结构枚举和有界采样，不称为穷尽所有姿态。改变物理过滤后，需要重新验收原始首帧、状态库和冲击峰值；出生状态落定结果也可能变化。
