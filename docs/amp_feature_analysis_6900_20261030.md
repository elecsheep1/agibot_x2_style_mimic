## 统计口径

每个样本是完整五状态窗口，不跨回合。未淡出阶段定义为窗口末帧 `hold_seconds <= 0.10`，包括俯卧、失败、恢复和边界窗口，不能全部解释成有效起身。15952 个总窗口中有 2367 个未淡出窗口。

匹配以检查点标准差归一化后，寻找全参考库最近的完整窗口，所有特征共享同一个最近邻；另报同出生动作内最近邻，避免跨动作匹配掩盖差异。没有按帧号强行对齐速度不同的动作。

误差用整个样本集合的 RMS，误差占比用平方误差总和。维数更多的块自然可能占比更大，须结合每维 RMS。它与旧 windows.json 中“每窗口 RMS 的均值”不同，不直接混比。关节行合并该关节的位置和速度；刚体行合并该刚体的位置、旋转、线速度和角速度。不同分类内部可比较，关节与刚体分类有不同数据块，不能作为同一分区相加。raw_feature_rms 可能混合已缩放单位，不能直接解释成米或弧度。

前三项速度共占 72.72%，四条出生动作分别匹配自身参考时，同样是速度类误差居前。不是只有一个腕部维度异常。刚体误差前列是右腕、左右肩、左腕，但腿部也有明显速度差异。

在未淡出窗口中均匀抽取最多 1024 个样本，固定原 D，将某组特征在整个窗口替换成全库最近参考窗口的对应值，再看分数变化。没有训练新网络。

|替换项|平均 D 分数变化|
|---|---:|
|全部身体相对旋转 6D（66维）|+0.2758|
|身体相对角速度（33维）|+0.1743|

替换全部身体相对线/角速度（66维）为 +0.3143；替换肩/髋/膝相对旋转（36维）为 +0.0761；替换胸/腕/踝相对旋转（30维）为 +0.1605。这些变化不可相加，也不能将不同维数组的变化当作公平的单维重要性排名。混合输入可能物理不一致、偏离训练分布；它们仅为敏感性线索，不能证明删掉这些特征会改善策略。

## 下一步候选

如果做最小改动对照，优先考虑仅移除 33 维身体相对角速度（233→200），保留根角速度、关节速度、五帧时间信息和所有姿态特征。它是候选实验，不是本报告已证明的最优配置。身体相对旋转虽敏感，但承载胸部、手脚朝向，不建议为追求分数抬升直接全部删除。先验证角速度数据的参考/仿真一致性也有价值，较大速度差可能来自节奏、碰撞和参考有限差分，而非特征本身无用。

目前没有改动 AMP 输入、训练奖励或配置，也没有启动训练。
