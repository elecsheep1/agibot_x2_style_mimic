# 后续任务：随机倒地出生（2026-11-05）

状态：用户要求记录，后续实现；本次不修改训练逻辑。

## 目标

将当前 50% 固定参考首帧出生的一部分逐步扩展为随机倒地姿态出生，保留参考过渡帧 RSI，以提升分布外倒地恢复能力。具体比例、扰动幅度和课程阈值在实现时再确定。

## 分阶段实施

1. 首帧附近扰动：随机选现有俯卧、仰卧等参考首帧，对关节角、身体朝向和速度做小幅扰动。处理落地高度，排除穿地、严重自交和不合理初始状态。
2. 仿真摔倒状态库：由站立、行走或受推后实际摔倒产生状态；保存根位姿、关节位置、根和关节速度以及来源信息。区分已静止倒地和仍带残余速度的状态。
3. 逐步混合：保留部分原始首帧，逐步增加扰动首帧和状态库比例，同时继续采样参考过渡帧 RSI。不要直接对全部关节进行大范围独立随机化。

## 出生类型与课程统计

显式记录出生类型，不再单独用 frame_ids == 0 识别基础验收回合：

- reference_initial：未扰动参考首帧。
- perturbed_initial：参考首帧附近扰动。
- fall_state：仿真摔倒状态库。
- reference_rsi：参考过渡帧。

辅助力课程初期仍由 reference_initial 且整回合零辅助的验收推动，保留现有按动作统计、曾成功及末态连续稳定条件。perturbed_initial 和 fall_state 单独统计，不能混入基础验收后让课程指标含义改变。零辅助抽样应避免与出生类型产生意外关联。

## AMP 历史

检查 AMP 历史缓冲和有效窗口逻辑。随机重置后必须清空上一回合历史，并按真实出生状态初始化；不能套用参考动作历史形成跳变。应明确窗口预热/有效掩码，不能把填充历史当作真实运动窗口。参考正样本生成流程不因随机出生而自动改变。

## 辅助力

沿用按实际骨盆高度衰减、达到撤力高度后整回合锁零的机制；高位 RSI 出生应直接零力。实际摔倒后如何辅助在实施时评估，不自动取消已约定的撤力锁定。

## 验收

- 检查各出生类型的实际采样比例、状态有效性和多环境隔离。
- 分别统计原始首帧、扰动首帧、摔倒状态库和过渡帧 RSI 的成功率及末态稳定率。
- 固定独立零辅助 OOD 验收集，区分俯卧、仰卧、左右侧卧及带残余速度；保留未参与训练的状态或扰动范围。
- 验证 reset、自动重置和 AMP 历史窗口不会跨回合污染。
- 当前优先完成基础起身和零辅助站稳，再实施随机倒地出生。
